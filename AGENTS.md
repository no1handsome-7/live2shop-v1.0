# Codex Development Workflow

## Superpowers

- Before development tasks, identify relevant installed
  Superpowers skills and follow their SKILL.md instructions.

- New features or major changes:
  Use brainstorming to clarify the design and obtain approval.
  Use writing-plans before implementation.

- Bug fixes:
  Use systematic-debugging to identify the root cause
  before modifying code.

- Implementation:
  Apply test-driven-development where practical.
  Add regression tests for bug fixes.

- Completion:
  Use verification-before-completion.
  Run relevant tests and report actual results.

## Project Safety

- Do not delete user data without approval.
- Do not change files outside the workspace without approval.
- Do not store cookies, credentials or tokens in the repository.
- Prefer Playwright MCP for browser-dependent page analysis.
- Respect website login requirements and access restrictions.
- For small changes, keep planning proportional to the task.
